# MMI 多路等分器优化

本章适用于以 MODE varFDTD 和原生 Optimization 优化 MMI 多路分光，并用全域 varFDTD 或 3D FDTD 复验的任务。先从已验证的 Layout 建立独立优化工程，读取交接书和原生属性确认当前基线、工艺与数值设置。下文的 1×8 为参数化示例，具体材料、尺寸、阈值、关断和优化预算以项目要求为准。

## 参数化与几何可行域

- 可先用输入 taper 的 MMI 端宽、MMI 长度、共用输出 taper 的 MMI 端宽和输出中心距做四参数优化。需要增加分光调节自由度时，把共用输出端宽替换为各镜像对的独立宽度。1×8 的端口按 y 从负到正编号，宽度向量为 `[w18,w27,w36,w45,w45,w36,w27,w18]`，共七个优化变量。四个新宽度初值取原共用宽度，窄端接入波导宽和 taper 长度继续用已确认的值。去掉多余的全局优化行，防止新旧属性同时驱动几何。
- 对等间距且关于 y=0 镜像的 1×8，设中心距为 `d`、MMI 宽度为 `W`。逐相邻对检查 `d - (w_i + w_{i+1})/2 >= gap_min`，并检查 `7*d + w18 <= W`。这两个式子适用于端宽定义在几何检查截面的直线 taper。若侧壁倾斜或其他截面更宽，按实际最宽包络检查间隙、连接和边缘。线性约束对独立参数盒可在角点或解析极值处验算。范围跨过可行域时，用声明清楚的可行参数映射，或显式处理不可行提案。静默 clamp 会让不同粒子落到同一几何，污染搜索历史。
- `runsetup()` 后回读实际实体。验证等宽时复现旧基线，逐组扰动只改对应两块 taper 及其宽度相关网格，再用四组不等宽的候选检查镜像关系、间隙、接合端面和 mesh 覆盖。MMI 长度应联动输出 taper、直段、测量面与下游边界，pitch 应联动输出中心线及监视器。宽度单独变化时，固定的中心线和测量面应保持原位。均匀测量直段与穿过 PML 的额外延伸分开记录。
- 顶层 setup 按名称维护器件和仿真对象，清理限于明确管理的对象。根级 `deleteall` 可能清除另行建立的 Analysis group 或监视器。保存并重开后，逐行核对实际 `::model::...` 参数路径、上下限、单位及唯一被选作优化目标的结果路径。Layout 回读证明配置与联动，实际模式身份另在求模预检或已有原生模式结果中核查。

## varFDTD、宽带和 y 对称

- MODE varFDTD 是基于有效材料的 2.5D 传播模型，本工作流使用 CPU。对平面 TE0 分光使用 `E mode (TE)`，以模式源沿传播方向注入，并在均匀输出直段逐路放置 DFT 与模式展开监视器。两者的平面、中心、横向窗口须匹配，`setexpansion` 逐路绑定。用缓存场型、偏振、芯区约束、`neff` 和节点确认基模。若源或展开监视器的缓存与截面不符，在独立 Layout 中更新并回读，避免直接依赖模式序号。
- 宽带优化时同时确认源和各展开监视器覆盖验收波段，明确指定波长采样方式，并包含实际中心采样点。使用 broadband 有效材料，核查有效折射率随波长的变化和时域能量是否衰减。曾出现过有效材料拟合过松导致色散丢失，以及更改拟合参数后出现时域能量增长的情况。把拟合设置、实际有效折射率、求解状态和原生日志一起看。用不同结束时间或关断阈值做对照时，保持空间网格不变，单独报告时间敏感性。
- y 场对称要求完整几何、材料、居中源及目标模式的矢量奇偶性相容。沿 +x 传播、主分量 `E_y` 对 y=0 为偶的基模 TE，在该镜面使用 `Anti-Symmetric` 作为待验证边界。回读实际对称面及计算半域，并用同一几何、网格目标、光谱和关断设置做全域对照，比较逐路 TE0、总插损及不均匀度。`force symmetric y mesh` 只是网格设置。y 的资格验证也只适用于该镜面。
- 对称资格通过后，1×8 半域可只启用正 y 的输出 5–8。对原生半域结果确认输入归一化后，按同波长复制 1↔8、2↔7、3↔6、4↔5，各路 `T_forward` 保持原值，八路只求和一次。记录哪些端口为直接求解、哪些为镜像恢复。带中心线输出的器件还需核对该端口的展开窗口和归一化，并只统计一次。镜像恢复得到的完全相等不构成对称边界验证。候选用于最终验证前，单独全域复验其八路输出。

## Model Analysis 与评价函数

在每个波长，令 `T_i` 为相对于入射 TE0 的各路前向 TE0 功率，来源为绑定的 mode expansion 结果 `T_forward`。定义：

- `η = Σ T_i`，`IL = -10 log10(η)`。
- `U = 10 log10(max(T_i)/min(T_i))`。按原始各路功率计算，不把通道功率重新归一化成总和为 1。
- 普通 DFT 窗口的净通量可辅助诊断，但不能替代 `T_forward`。窗口通量和模式功率可能落在插损阈值两侧，二者差额也不能直接解释为某一种损耗。

对严格中心阈值 `IL < L_lim`、`U < U_lim`，可在功率域等价检查 `η > 10^(-L_lim/10)`、`max(T_i)/min(T_i) < 10^(U_lim/10)`。验收使用未舍入值。若波段目标是逐波长 dB 指标的算术平均，直接在已确认的采样网格求均值。单点、波段均值、最差值和逐点达标范围分别报告。

- 对 Maximize 的原生 PSO，可显式分层。任何中心两项均达标的候选得分高于有效但未达标的候选。可行分支优先降低 `U`，同时考虑插损余量和波段软目标。未达标分支给出有方向的缺额评分，保留已验证的达标几何作为对照，支持时也可纳入初始候选。改动均匀度搜索尺度时同步审查插损权重与可行分支。把归一化尺度从 0.1 dB 收紧为 0.01 dB，会让相同功率比偏差的罚项放大约十倍。如果还把可行门槛一起收紧，原来满足用户目标的点也可能降入低分分支。单独保留正式验收口径，跨评分版本比较原始 IL、U 和谱线。
- Analysis 只读已有结果。入口把 FOM 重置为明确的无效标记，避免异常早退保留旧分数。逐路检查结果长度、完整波长向量的一致性，以及目标采样点和波段端点。对整段检查功率是否为有限、非负的实数，检查功率和的物理范围与约定的求解完成状态，之后才计算并提交有效 FOM 和候选记录。循环里先标记异常并结束循环，在外层再退出 Analysis，避免继续使用部分填充的数组。零功率保存为原始值，其负 dB 为负无穷。若评价式要求严格正功率，按既定规则拒绝评分。模式缓存、结果缺失或发散属于运行错误，不能混入普通低分候选。
- 用已存谱线回放，独立计算指标和 FOM，再注入单路波长错位、带尾异常总功率、零或非有限功率、未完成状态等故障。检查故障路径不会产生有效分数或完成记录。用同一镜像数据回放半域与全域分支可测试计算逻辑，物理半域验证需使用独立全域求解结果。

## PSO 记录、跨机回收与 3D 复验

- 按测得的候选耗时、并行资源和总预算设种群及最多代数，留出复验时间。保存实际算法、方向、随机策略、代数上限、容差、FOM 版本和参数顺序。按完整一代检查当代最佳和累计最佳，稳定的个别候选可单独诊断。边界最佳点应标注触及的具体参数，扩大范围前重新验算物理可行域。
- 每个候选按原生代号和成员号关联参数、实际宽度、得分、求解状态和逐点谱线。相同几何可能在多代出现，参数向量不足以唯一定位求解记录。从 `getsweepresult` 的 `parameter history`、`fom history` 或真实完整代回调核对已完成代数，并区分配置上限、报告的进度和可验证的结果。`*_best_solution.lms` 可能只带单点结果，即使保存了 `opt` 对象，也应查询 `getsweepresult` 才能判断历史是否存在。只有最佳点时报告该点的独立核验，代际收敛和停止原因留为未验证。
- 外机运行前验证工作目录、结果目录和候选记录路径可写且可迁移。确保能带回含历史的主 LMS 或原生历史导出、完整代记录、最佳点及依赖文件。对返回文件做只读重开，核对实际几何、数值设置、当前 Analysis 的门槛、波长网格、求解状态和哈希。以端口原始谱线重算 IL、U 和 FOM，结合输入及各实测输出的原生模式结果核验身份。保留线性功率和负 dB 谱图，以及单独的 IL/U 图与参数表。
- 3D 验证应绑定同一候选的实际几何和端口定义。比较 EME、varFDTD 和 3D 时，在相同入射模式及波长网格下报告逐端口、中心与宽带差值，说明各自的网格、边界、终止条件和已验证层级。EME 均匀段长度传播参考、2.5D 优化结果和 3D 实际求解分别标明。旧几何的 3D 结果只能用来比较该旧几何的模型差异。
- 3D 工程先评估运行机的主机内存、GPU 显存和磁盘空间。需要跨机时，便携包应包含独立 pre-run 与运行副本、候选与仿真配置、目标机的资源预检步骤，以及回收说明。返回分析工程、原生输出及日志时，保持工程与 H5 等外部结果的相对路径。确认实际几何和原生结果可独立重开，再作性能判断。
